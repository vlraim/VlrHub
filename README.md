# VlrHub

A modern Roblox Script & Executor Hub built as a fully functional dark-themed website.

## Features

- 200 script entries with categories, tags, game names, status, and copy actions
- Search, filters, and sorting across script directory
- Verified, keyless, and key-required script coverage
- Executor directory with compatibility and supported platforms
- Favorites and saved scripts systems using localStorage
- Recently viewed tracking and profile section
- Themes: Black, Purple, Blue, Red, Green
- Dark/light mode with customizable accent colors
- Responsive layout for mobile and desktop
- Admin dashboard for adding scripts locally

## Run locally

Open `index.html` in a browser, or serve the project from a local static server:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000

## Notes

This project is structured as a working static single-page app so all core interactions function immediately without additional setup.
